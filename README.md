# Sunrise Avenue – Flats Booking Website

A simple static website for browsing flats at **Sunrise Avenue**.  
Built using **HTML**, **CSS**, and **Bootstrap 4**.

## Features
- Home page and flat listings
- 2BHK, 3BHK, and 4BHK details
- Responsive layout with Bootstrap
- Simple section navigation

## Technologies
- HTML5
- CSS3
- Bootstrap 4

## How to Run
- Open `Flat.html` using **Live Server** or directly in a browser
